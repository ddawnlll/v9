# M1-05 (#14) — 28 expert witnesses as context-aware evidence producers

**Status: implementation COMPLETE, acceptance tests exercised (16 fast + 1 slow passed), ruff + mypy
clean.** 28/28 canonical witnesses emit exactly one context-bound evidence row each; duplicates and
aliases collapse; warmup/missing-input/quality/horizon/dependency-group shortfalls abstain with a
typed reason; the layer with contexts disabled reproduces the plain registry's stance kinds and
reason codes exactly, on synthetic bars and on the real Q1 tape.

## 1. Objective

Turn the 28 canonical expert observers (`v8_next.experts.registry`) into evidence producers that
receive the V9 context layer (`ObservationView`, `HorizonContext`, optional `MarketBeliefV1`) as
*inputs*, and expose versioned, deterministic SUPPORT/CONTRADICT/ABSTAIN evidence — without giving
witnesses opportunity-creation authority, capital, or any execution capability. Contexts are inputs,
not 28 separate opportunity creators.

## 2. Implementation — `src/v8_next/experts/evidence.py` (new, 656 lines)

### 2.1 Models (frozen, `extra="forbid"`, version-pinned)

`ExpertEvidenceV1`

| field | meaning |
|---|---|
| `expert_id` | canonical registry id; validated as one of the 28 (`squeeze_swing`, aliases, unknown ids rejected) |
| `expert_version` | registry `ExpertSpec.version` |
| `stance` | the registry's `StanceKind` (support/contradict/abstain) |
| `confidence` | `Decimal`; **assertion determinacy** — `1` when the expert asserted, `0` on abstention. Never a probability; no calibration claim |
| `reason` | the expert's own reason code, or a typed `EvidenceReason` when the layer abstained first |
| `input_dependency_group` | deduplicated group id derived from `ExpertSpec.requires` (`requires:history\|location\|volatility`), validated against the registry |
| `warmup_ok` | `len(frame.candles) >= ExpertSpec.warmup` |
| `context_ref` | digest of belief version hash + 15m/1h/4h as-of/complete/quality + usable observation ids |
| `evidence_id` | `canonical_digest("expert-evidence", …)` over exactly the row's content |
| `advisory_only`/`order_authority` | `Literal[True]`/`Literal[False]`, enforced |

`EvidenceBundle`: `instrument`, `decision_time_ns`, `belief_version_hash`, `context_ref`, `evidence`,
`abstain_count`, `duplicate_witness_ids`, `coverage`, `input_dependency_groups`, `provenance`,
`context_layer_enabled`, plus the same advisory/authority pins. Validators enforce: unique experts,
canonical registry order, `coverage == len(evidence)`, `abstain_count` matches the rows, every row
bound to the bundle `context_ref`, deduped group set, 64-hex digests, version equality.

`EvidenceReason` codes are deliberately distinct from every expert reason so "the layer withheld
this witness" is distinguishable from "the witness looked and found nothing": `WARMUP_INPUT`,
`MISSING_INPUT`, `INPUT_QUALITY`, `CONTEXT_INCOMPLETE`, `DEPENDENCY_UNAVAILABLE`.

### 2.2 `produce_evidence(...)`

```
produce_evidence(*, view, context, frame, cache, belief=None, opportunity=None,
                 readings=(), observers=None, unavailable_dependency_groups=(),
                 context_layer=True) -> EvidenceBundle
```

* **Canonical dispatch only.** With the layer enabled each non-gated expert is dispatched through
  `v8_next.experts.registry.observe_expert` inside `FeatureCache.scoped(frame)` (the registry's own
  observer functions, witness metadata and retained indicator state). No expert rule is
  reimplemented.
* **Gate order (documented, first wins):** dependency group unavailable → warmup → blocked input
  quality (view, and belief when supplied; `MISSING`/`UNKNOWN`/`CONTRADICTORY`/`AMENDED_FUTURE`
  block, `STALE` does not) → decision horizon absent/incomplete/blocked (the frame's own
  `Timeframe` alignment) → required positioning readings absent. Gated experts are never called, so
  an unavailable dependency group abstains instead of crashing or fabricating.
* **Dedupe.** `observers` may list canonical ids, aliases or repeats; all resolve through
  `EXPERT_REGISTRY` to the canonical witness, are returned in canonical order, and repeated ids are
  reported in `duplicate_witness_ids`. Unknown ids raise `KeyError`; an empty selection raises.
  The bundle validator refuses duplicate expert rows outright.
* **Fail-closed contract errors** (`ValueError`): view cut after the decision (future input), context
  naming another instrument/decision time, belief naming another instrument/decision time, tampered
  belief hash (`BeliefIntegrityError`).
* **Baseline-off parity.** `context_layer=False` is the comparison path: it calls
  `FeatureCache.observe_all_28` (the registry's 28-wide dispatch) and forwards every stance kind and
  reason code untouched; only `warmup_ok`/`context_ref` annotations are added.
* **No authority.** The module imports no execution, order, broker, adapter, portfolio or capital
  surface (AST-checked in the tests), exposes no `opportunity_at`, creates no opportunity (the
  `opportunity` argument is a pass-through identity created upstream), and every model carries
  `advisory_only=True` / `order_authority=False`.

### 2.3 Provenance

`provenance = canonical_digest("expert-evidence-provenance", {version, registry ids, expert
versions + registry dependency groups, cache version, cache input digest, context_ref,
belief_version_hash, context_layer, unavailable groups, readings count})`. `input_dependency_groups`
is the deduplicated, sorted set of requirement groups the rows read (14 distinct groups over the 28
experts).

`src/v8_next/experts/__init__.py` re-exports `EVIDENCE_VERSION`, `EvidenceBundle`, `EvidenceReason`,
`ExpertEvidenceV1`, `produce_evidence` (existing exports unchanged).

## 5. Residual risks and NOT_RUN / BLOCKED

| Item | State | Reason |
|---|---|---|
| Wiring evidence into `TraderDecisionPolicy` / entry intent | **NOT_RUN** | out of this slice: the ticket assigns the producer module only; no decision-policy consumer was changed |
| Full 2,160-bar replay cost of `produce_evidence` | **NOT_MEASURED** | `context_ref` digests the usable observation-id list per call (O(n) per decision, as specified); the hot 28-wide replay path stays on `observe_all_28`. Only 125/260-bar frames were exercised |
| Positioning witnesses with real funding/OI readings | **NOT_RUN** | the tape carries funding, but this slice supplies readings only in synthetic tests; the tape test exercises their explicit `MISSING_INPUT` abstention |
| Confidence calibration | **NOT_CLAIMED** | `confidence` is assertion determinacy (1/0), not a probability; no calibration or economic claim is made anywhere |
| 40-leg / 12-month tape, PnL, live trading | **NOT_RUN** | single-leg Q1 tape only; no economic or live-trading claim |
| Aliases beyond the registry table | **NOT_RUN** | only registry-declared ids/aliases are resolvable; anything else raises `KeyError` by design |

Known deliberate detail: with `context_layer=False` the bundle is the registry's raw output
(including its own `WARMUP`/`NO_OPPORTUNITY` reasons), which is exactly the baseline the parity test
compares against; typed layer reasons appear only when the context layer is enabled.
