## Separation of authorities

- `PositionThesis` stores the **original** entry decision, opportunity, belief id, native position id,
  entry/stop, original risk, target plan, invalidation rules and policy version. It is frozen and
  `advisory_only=True`; there is no method that mutates the stop.
- `PositionSnapshot` is the caller-supplied native state (quantity, mark, protective order ids,
  funding exposure, elapsed bars, availability). It is replaced, never edited in place.
- `evaluate_position` is pure and returns an explanatory `PositionEvaluation` with advisory
  proposals. Native stop ownership and order side effects remain outside this module.

## Semantics

| Condition | Status | Proposal |
|---|---|---|
| fresh belief, rule set intact | `HOLDING` | `HOLD` |
| mark crosses the original stop | `INVALIDATED` / `STOP_BREACHED` | `EXIT` |
| regime differs from `entry_regime` | `INVALIDATED` / `REGIME_CHANGED` | `EXIT` |
| weighted contradiction >= threshold | `WEAKENING` / `EXPERT_CONTRADICTION` | `REDUCE` |
| elapsed bars >= `max_bars` | `WEAKENING` / `TIME_LIMIT` | `REDUCE` |
| no protective order | `WEAKENING` / `PROTECTION_GAP` | `WAIT`, not admitted |
| stale / missing / abstaining belief, future input, position-id mismatch | `MISSING_INPUT` | `WAIT` |
| native quantity zero | `CLOSED` | `WAIT` |

A protection gap always yields `WAIT` (even with other weakening reasons), so the evaluator never
proposes a blind action while protection is unknown.

## Determinism

`thesis_id`, `evaluation_id` and `ThesisHistory.digest` are SHA-256 over canonical content, with no
wall clock. Replaying the same inputs returns the identical thesis, evaluation and history. The
history accepts an identical evaluation idempotently and rejects another thesis's evaluation.

## Not claimed

- No stop amendment, no native order and no risk authority. Proposals are advisory inputs to the
  unified policy/risk path.
- No economic claim. Belief is consumed through an explicit `ThesisBelief` projection so a belief
  schema change cannot silently reinterpret a historical evaluation.
