## Semantics

| Condition | Mode | Reason |
|---|---|---|
| `now < valid_after` | `NOT_YET_VALID` | `ENTRY_NOT_YET_VALID` |
| `now >= expires_at` / cancelled state | `CANCEL_STALE` | `ENTRY_EXPIRED` |
| venue status `UNKNOWN` | `CANCEL_STALE` | `VENUE_UNKNOWN` |
| stale/unavailable belief | `WAIT_BELIEF` | `BELIEF_STALE` / `DATA_MISSING` |
| quote `available_at > now` | `WAIT_BELIEF` | `FUTURE_QUOTE` |
| price outside band | `SKIP_PRICE` | `PRICE_OUTSIDE_BAND` |
| market + observed touch | `MARKET_NOW` | `ENTRY_READY` |
| market + no spread | `WAIT_BELIEF` | `DATA_MISSING` |
| limit/post-only | `LIMIT_WAIT` | `ENTRY_READY` |

- A touched limit is at most `TOUCHED_ONLY`; without bid/ask it is `UNKNOWN`. No path emits a
  fill probability or claims a fill.
- `revise()` returns a new immutable revision with a new deterministic `intent_id`; the original is
  untouched. `cancel()` only marks the proposal; no native cancel is sent.
- `advisory_only` is pinned `True`; `extra="forbid"` rejects order-shaped fields such as `quantity`.
- Unknown venue state blocks all new entries (fail closed).
